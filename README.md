dsa for beginners
=================

data structures & algorithms, explained the way a friend would explain it over chai.
no mugging up solutions — we learn the **pattern**, then practice until it sticks.

code is in **Java**. every problem goes: brute force → optimal → dry run → complexity → mistakes we actually made.

how to use this
---------------

1. read the concept part of a topic
2. open the problem on LeetCode and **try it yourself first** (20–30 min)
3. stuck? read the hint, not the solution
4. after solving, read the "mistakes" section — that's where the real learning is
5. come back after 3 days and solve it again without looking
